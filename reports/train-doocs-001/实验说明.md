# train-doocs-001 实验记录

本目录为真实完成的 0.5B QLoRA 实验轻量归档，可随 Git 同步。它不是模型分发包，不包含适配器、基础权重或完整恢复检查点。

## 训练结果

- 数据：训练 2,292、验证 129，留出 123；对应文件 SHA 在 run_manifest.json 中。
- 配置：2048 token、rank 8、梯度累积 4、2 轮、1,146 个优化器更新步；精确配置记录在 run_manifest.json 的 config 字段。
- 最佳检查点：checkpoint-1100，验证损失 0.3515698。
- 最终 eval_loss 是 Trainer 重载最佳已保存检查点后计算的，不表示最后一步权重优于所有历史检查点。
- 总耗时约 4,847 秒；PyTorch peak allocated 约 4.47 GiB。peak reserved 记录为 14.19 GiB，该计数不应直接当作设备专用显存容量或其他机器的容量保证。
- 源代码提交与脏工作区标记、模型 revision、版本与硬件使用原运行清单的真实值，未改写成归档时的状态。

## 已归档文件

| 文件 | 用途 |
| --- | --- |
| run_manifest.json | 原训练清单，含配置、数据 SHA、基础模型 SHA、版本、硬件和代码状态 |
| run_status.json | completed，最终步数 1146、最佳检查点路径 |
| metrics.json | 训练及验证汇总 |
| training_log.jsonl | 逐步损失、梯度、学习率、轮数和历次验证日志 |
| predictions.jsonl | 保留的 20 道算法评估题的模型原始回答 |
| predictions.manifest.json | 生成参数、题库/模型/预测 SHA 与完成状态 |
| archive_manifest.json | 原文件位置、归档文件 SHA、导出脚本 SHA 及执行报告归档状态 |
