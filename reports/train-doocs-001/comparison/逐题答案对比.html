回文数

给你一个整数 x ，如果 x 是一个回文整数，返回 true ；否则，返回 false 。

回文数是指正序（从左向右）和倒序（从右向左）读都是一样的整数。

例如，121 是回文，而 123 不是。

 

示例 1：

输入：x = 121
输出：true

示例 2：

输入：x = -121
输出：false
解释：从左向右读, 为 -121 。 从右向左读, 为 121- 。因此它不是一个回文数。

示例 3：

输入：x = 10
输出：false
解释：从右向左读, 为 01 。因此它不是一个回文数。

 

提示：

-2^(31) <= x <= 2^(31) - 1

 

进阶：你能不将整数转为字符串来解决这个问题吗？

接口：
```python
class Solution:
    def isPalindrome(self, x: int): ...
```

基础模型原始回答

```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        # 将整数转换为字符串
        str_x = str(x)
        
        # 检查字符串是否为回文
        return str_x == str_x[::-1]
```

微调模型原始回答

```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        if x < 0:
            return False
        y = 0
        while x:
            y = y * 10 + x % 10
            x //= 10
        return y == x
```

盛最多水的容器

给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明：你不能倾斜容器。

 

示例 1：

[图片： https://fastly.jsdelivr.net/gh/doocs/leetcode@main/solution/0000-0099/0011.Container%20With%20Most%20Water/images/question_11.jpg]

输入：[1,8,6,2,5,4,8,3,7]
输出：49 
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。

示例 2：

输入：height = [1,1]
输出：1

 

提示：

n == height.length

2 <= n <= 10^(5)

0 <= height[i] <= 10^(4)

接口：
```python
class Solution:
    def maxArea(self, height: List[int]): ...
```

基础模型原始回答

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        if not height:
            return 0
        
        left, right = 0, len(height) - 1
        max_area = 0
        
        while left < right:
            area = min(height[left], height[right]) * (right - left)
            max_area = max(max_area, area)
            
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        
        return max_area
```

微调模型原始回答

```python
from typing import List

class Solution:
    def maxArea(self, height: List[int]) -> int:
        ans = mx = 0
        l, r = 0, len(height) - 1
        while l < r:
            if height[l] > height[r]:
                mx = max(mx, height[r])
                ans = max(ans, mx * (r - l))
                r -= 1
            else:
                mx = max(mx, height[l])
                ans = max(ans, mx * (r - l))
                l += 1
        return ans
```

三数之和

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

 

 

示例 1：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

示例 2：

输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。

示例 3：

输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。

 

提示：

3 <= nums.length <= 3000

-10^(5) <= nums[i] <= 10^(5)

接口：
```python
class Solution:
    def threeSum(self, nums: List[int]): ...
```

基础模型原始回答

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []
        for i in range(len(nums)):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            left, right = i + 1, len(nums) - 1
            while left < right:
                if nums[i] + nums[left] + nums[right] == 0:
                    res.append([nums[i], nums[left], nums[right]])
                    left += 1
                    right -= 1
                elif nums[i] + nums[left] + nums[right] < 0:
                    left += 1
                else:
                    right -= 1
        return res
```

微调模型原始回答

```python
from typing import List

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        ans = []
        for i in range(len(nums) - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            j, k = i + 1, len(nums) - 1
            while j < k:
                s = nums[i] + nums[j] + nums[k]
                if s == 0:
                    ans.append([nums[i], nums[j], nums[k]])
                    j += 1
                    k -= 1
                    while j < k and nums[j] == nums[j - 1]:
                        j += 1
                    while j < k and nums[k] == nums[k + 1]:
                        k -= 1
                elif s < 0:
                    j += 1
                else:
                    k -= 1
        return ans
```

示例 2：

输入：digits = "2"
输出：["a","b","c"]


基础模型原始回答

```python
from typing import List


class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []

        # 构建字母映射
        mapping = {
            '2': 'abc',
            '3': 'def',
            '4': 'ghi',
            '5': 'jkl',
            '6': 'mno',
            '7': 'pqrs',
            '8': 'tuv',
            '9': 'wxyz'
        }

        # 初始化结果列表
        result = []

        # 递归生成字母组合
        self.dfs(digits, mapping, result, [])

        return result

    def dfs(self, digits: str, mapping: dict, result: List[str], path: List[str]) -> None:
        if len(path) == len(digits):
            result.append(''.join(path))
            return

        for char in mapping[digits[len(path)]]:
            self.dfs(digits, mapping, result, path + [char])
```

```python
from typing import List

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        d = {
            "2": "abc",
            "3": "def",
            "4": "ghi",
            "5": "jkl",
            "6": "mno",
            "7": "pqrs",
            "8": "tuv",
            "9": "wxyz",
        }
        n = len(digits)
        ans = []
        for i in range(1 << n):
            s = []
            for j in range(n):
                if i >> j & 1:
                    s.append(d[digits[j]])
            ans.append("".join(s))
        return ans
```

```python
class Solution:
```

```python
        if n == 0:
            return []

            return ['()']

        left = self.generateParenthesis(n - 1)
```

```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        # 检查每一行
        for i in range(9):
            row = set()
            for j in range(9):
                if board[i][j] != '.':
                    row.add(board[i][j])
            if len(row) != 9:
                return False
        
        # 检查每一列
        for j in range(9):
            col = set()
            for i in range(9):
                if board[i][j] != '.':
                    col.add(board[i][j])
            if len(col) != 9:
                return False
        
        # 检查每个以粗实线分隔的 3x3 宫
        for i in range(3):
            for j in range(3):
                subgrid = set()
                for k in range(3):
                    for l in range(3):
                        if board[k+i][l+j] != '.':
                            subgrid.add(board[k+i][l+j])
                if len(subgrid) != 9:
                    return False
        
        return True
```

微调模型原始回答

```python
from typing import List

class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        squares = [[set() for _ in range(3)] for _ in range(3)]

        for i, row in enumerate(board):
            for j, val in enumerate(row):
                if val == ".":
                    continue
                if val in rows[i]:
                    return False
                if val in cols[j]:
                    return False
                if val in squares[i // 3 * 3 + j // 3]:
                    return False
                rows[i].add(val)
                cols[j].add(val)
                squares[i // 3 * 3 + j // 3].add(val)

        return True
```

```python
class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        # 将列表转换为字符串，然后通过切片操作添加 '1'，最后转换回列表
```

```python
from typing import List

class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        n = len(digits)
        for i in range(n - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0
        return [1] + [0] * (n + 1)
```

给你两个二进制字符串 a 和 b ，以二进制字符串的形式返回它们的和。

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        # 将字符串转换为整数
        num_a = int(a, 2)
        num_b = int(b, 2)
        
        # 计算和
        result = num_a + num_b
```

```python
                return False
        
        # 如果所有字符都已成功添加到字典中，返回 True
        return True
```
