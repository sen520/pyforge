# 训练数据执行审计

## 本次结论

2026-10-23 对训练/验证集中的上游题解固定抽样 200 题，189 题通过本地用例，11 题暂缺接口适配。没有发现可确认的答案错误，但这些有限用例不能证明全部题解正确，也不能代表模型通过率。

原始执行记录为 189 passed、10 unsupported_adapter、1 runtime_error。最后一项是 2936 题要求 BigArray.size()/at()，检查器误传普通列表导致的异常；分类记录将其归入接口未适配，原始日志未改写。题解不应因此被删除。

此外，检查全部训练/验证上游样本的 AST，找到 57 条题面仅声明辅助类、答案却包含 Solution 主接口的样本：训练 54 条、验证 3 条。例如 947 题的题面只列出 UnionFind。原因是提取器采用 Python 代码中的第一个类。该问题值得修复；目前证据不能证明它是模型退步的唯一或主要原因。

## 抽样与用例

抽样总体为训练/验证的 2,326 条上游题解，不读取测试集。按集合与难度比例分配 200 个名额，使用最大余数法处理整数余量；每层按 SHA256("audit-v1:42:" + id) 排序取样。不能在执行失败后替换样本。

| 集合 | 简单 | 中等 | 困难 | 合计 |
|---|---:|---:|---:|---:|
| train | 50 | 100 | 39 | 189 |
| validation | 3 | 6 | 2 | 11 |

冻结清单含 462 个题面示例、290 个 Codex 独立编写的正常/边界用例；独立用例覆盖 91 题，并非全部 200 题都有独立边界测试。只使用题目输入约束允许的情况，不把非法输入异常算作答案错误。浮点数使用 1e-6 容差；无序、多解题使用专用比较器，含峰值下标、无零整数对、距离排序、小和数对、三元分组。

候选答案只在无网络、只读文件系统、普通用户、限制 CPU/内存/进程数的 Docker 容器中执行。每题 15 秒，使用固定镜像 ID；自动执行和 Codex 分类都不标记为人工审核。

## 运行与文件

```powershell
# 先冻结样本与用例，默认不执行答案
python scripts/audit_training_data.py --output reports/data-audit-v2
# 启动 Docker Linux 引擎，并确保本地有 python:3.12-slim 镜像
python scripts/audit_training_data.py --output reports/data-audit-v2 --execute
# 保存分类与训练/验证接口问题清单，不覆盖原始结果
python scripts/review_data_audit.py --output reports/data-audit-v2
```

审计目录必须与当前数据、脚本、用例和镜像条件一致，变化时换新目录。中断后相同条件再次执行可从 results.jsonl 继续。review 脚本内的 BigArray 分类仅适用于 2936 题记录中的明确异常；其他答案不符保留 requires_review，需要继续核对。

已提交的 [data-audit-v1](../reports/data-audit-v1/审计说明.md) 包括 sample.json、execution_manifest.json、results.jsonl、summary.json、review.json 和逐题表。sample 保存题号、来源、答案哈希和具体用例；summary 保留原始运行计数；review 保存分类及 57 条接口问题。

恢复脚本核对修复前哈希；输出仅 train/validation，供算法评估检查训练题重叠，不作为恢复训练的完整数据目录。直接使用当前数据恢复旧 checkpoint 会被哈希检查拒绝。

随后从同一基础模型分别训练两组 1 epoch：学习率 1e-4 和 3e-5，其他数据、seed、LoRA 与生成参数一致。不要接着旧 adapter 训练后再宣称单变量对照。比较基础模型和两组模型的逐题执行结果；学习率降低只是待验证假设。
