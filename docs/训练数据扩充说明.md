## 答案来源与筛选

每题选取与公开类、方法接口匹配的首个可接受 Python 实现；代码仅解析，不在宿主执行。记录为 `upstream_reference_not_codex_authored`，作者为上游贡献者，保留原题、上游路径、固定提交链接、原文 SHA、许可与修改说明。答案只保留代码，不复制思考段落；也不将参考实现放入 user 提示。

过滤规则包括：

- 排除原有 20 道可执行评估题，以及旧题面导入时已排除的 47 个种子相同/近似题。
- 排除依赖图片的题面。
- 拒绝 Python 语法错误、接口不匹配、顶层执行语句、非标准库导入以及无法补齐的全局依赖（例如 SortedList、未适配的 ListNode）。会继续尝试同题后续 Python 实现。
- 可识别的 List、Counter、cache、inf、heapq/bisect 等依赖按白名单添加明确导入。
- 使用固定本地 tokenizer 和原生聊天模板检查完整问答，超过 2048 token 整条排除，不截掉答案。

本轮 3,422 题中未加入 973 题，其中 844 题含图片，20 题保留为独立执行评估，其余主要为未适配依赖或顶层执行语句。逐题原因见 `datasets/metadata/doocs_sft_v1/manifest.json`。

新增全部 2,449 条通过语法及上述静态检查，**没有逐题执行验证**，不应标为算法正确或人工审核通过。它们是用于下一轮实验的静态检查参考答案，不等同于旧 100 条已执行数据的质量保证。新测试集也只有参考答案，没有通用执行器。

此前整批 doocs 题目预留作评估；本次用户已明确授权转出一部分用于训练。因此完整 `benchmarks/doocs-leetcode/questions.jsonl` 现为来源目录，不能整体宣称独立评估。只有保留的 20 题执行子集，以及本次新划分、未用于训练的题目继续用于评估；公开题预训练污染风险仍存在。

## 训练与复现

```powershell
# 使用扩充数据，从基础模型初始化新 LoRA；不恢复旧检查点
pyforge train --config configs/train_4060.json --data datasets --output outputs/train-doocs-001 --offline
```

4060 新配置为 0.5B、2048 token、rank 8、梯度累积 4、2 轮，每 100 步评估并保存，预计约 1,146 个更新步。该 2048 配置尚未完成整轮 GPU 训练验证。旧 512 token smoke 配置可以保留用于排错，但新增样本中只有 858 条能在该限制内编码。

已有本地固定上游快照和模型缓存时，重建到新的输出目录：

```powershell
python scripts/build_leetcode_training.py --output outputs/doocs-sft-rebuild-001
python -m unittest discover -s tests -v
```

脚本默认读取 `data/sources/doocs-leetcode`、历史题面来源文件与 `datasets/archive/codex_v1/`。输出包含 train/validation/test、manifest 和 LICENSE，拒绝覆盖已有目录，不自动覆盖默认数据。与默认数据的哈希应核对后再替换。模型训练仍需记录本次数据 SHA；历史模型 train-002 的恢复或评估应使用历史归档文件，不能套用新数据。
