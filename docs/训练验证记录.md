# 训练验证记录

> 本文保留最初 10 步冒烟与恢复的历史记录。当前 2048 token、2 轮、1,146 步训练也已完成，精确清单与日志见 [train-doocs-001 实验记录](../reports/train-doocs-001/实验说明.md)。不同数据集的验证损失不能直接比较。

## 环境

本次在原生 Windows、Python 3.12.0、NVIDIA GeForce RTX 4060 Laptop GPU（8 GB）运行，使用 torch 2.6.0+cu124、transformers 4.57.6、peft 0.18.1、accelerate 1.15.0、bitsandbytes 0.48.2。训练扩展依赖已在 `pyproject.toml` 固定为这些版本；CUDA 下载源仍需单独指定。

基础模型为 `Qwen/Qwen2.5-Coder-0.5B-Instruct`，实际快照 SHA 为 `ea3f2471cf1b1f0db85067f1ef93848e38e88c25`。使用 `configs/smoke_4060.json` 与当前 `datasets/leetcode/`。

## GPU 训练与恢复

执行 `--offline --stop-after 2` 后得到完整 `checkpoint-2`，再在新进程中恢复到第 10 步。恢复过程读取了优化器、调度器、随机状态及 Trainer 状态，训练正常续接至第 3 步，最终状态为 completed。

| 检查 | 实测结果 |
| --- | --- |
| 编码 | 90 条训练、5 条验证全部保留，超长过滤 0 条 |
| 训练标签 | 15,789 个训练 token，其中 9,125 个参与损失 |
| 可训练参数 | 4,399,104，仅 LoRA 参数参与更新 |
| 检查点验证损失 | 第 2 步 1.494515；第 5 步 1.415222；第 10 步 1.381097 |
| 最佳检查点 | checkpoint-10 |
| 恢复运行峰值 allocated | 约 1.52 GiB |
| 恢复运行峰值 reserved | 约 3.41 GiB |
| 恢复运行耗时 | 约 24.8 秒，包含加载和保存；与机器状态有关 |

测试集 5 条只做格式和泄漏检查，没有参与损失计算。模型权重、完整检查点与运行日志留在忽略的 `outputs/training-smoke-001/`，不提交 Git。

训练结束后，在全新进程执行 `pyforge chat --run outputs/training-smoke-001 --offline --max-new-tokens 128 --prompt "编写一个 Python 函数，判断整数是否为偶数。"`，成功加载固定基础模型与适配器，生成 `is_even(number)`，函数返回 `number % 2 == 0`。128 token 上限可能截断后续文字说明，本次仅确认重载和生成可用。

本次验证用于确认训练链路可执行，不构成模型能力提升证据。RTX 4080 SUPER 与 1.5B 正式配置尚未实测。
