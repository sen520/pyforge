# doocs 算法验证候选集

## 来源与当前结果

来源为 [doocs/leetcode](https://github.com/doocs/leetcode)，固定提交 `757ae31a437dc98972e73057f122a7c947acf8d7`。本轮提取 `solution/*/*/README.md` 的中文题面和首个可解析 Python 类公开接口，不包含剑指 Offer、面试金典等其他目录。

当前共 3,422 题：简单 788、中等 1,869、困难 765。数据在 `data/validation/doocs-leetcode/questions.jsonl`，随附 `manifest.json` 与上游 `LICENSE`。本地原始稀疏仓库在 `data/sources/doocs-leetcode`。这两个目录均受 Git 忽略，不提交外部仓库与整份第三方题面；项目提交导入脚本、排除规则和可追溯清单。

## 提取边界

只保留明确的 description 标记之间的题面，HTML 转为文本，保留示例、约束、公式上下标及图片链接。从 Python 题解只提取类名、公开方法名和参数，方法体替换为省略号；不运行上游代码，不把解题思路或参考实现放入模型请求。原文 SHA 与固定提交链接可追溯转换来源。

无题面标记、无可解析 Python 类接口等项目被跳过，原因写入清单。链表、二叉树、设计类、交互题及依赖图片的题目尚未建立统一执行适配器。部分题目的数据范围或数学排版仍须人工复核。

## 用途与污染控制

本数据指定为验证候选集，不能用于教师作答生成训练样本，也不能混入 `pyforge prepare` 的随机划分输入。现有训练入口的 validation.jsonl 是 messages 格式的监督损失验证集，与这里待建立执行器的算法评估集不同。

`configs/leetcode_overlap.json` 保守排除已识别的种子题相同或近似任务，例如两数之和、合并区间、二分查找、斐波那契。它是初步人工映射，不是完整语义去污染；后续种子题增加或改写时必须更新规则并重建新版本。题目 ID 作为 group_id，当前无法自动识别所有不同题号的近似题。

公开 LeetCode 题可能已在基础模型预训练中出现，只适合辅助比较，不能宣称完全未见题的泛化能力。若用本集合调参，最终效果应另用冻结的独立测试集确认。

## 执行评估尚待完成

每条记录标记 `execution_ready=false` 和 `candidate_requires_review_and_tests`。题面展示的例子不等于完整隐藏测试，参考题解也不能代替正确性证明。后续应选择适合单函数执行的一批题目，补充独立边界测试、输出比较器、结构化输入适配及隔离执行器，再冻结可执行子集。未完成前不计算 pass@1。

## 复现

已有本地稀疏仓库时可直接重建到新目录：

```powershell
python scripts/import_leetcode.py --output data/validation/doocs-leetcode-v2
```

新环境获取相同输入：

```powershell
git clone --depth 1 --filter=blob:none --no-checkout https://github.com/doocs/leetcode.git data/sources/doocs-leetcode
git -C data/sources/doocs-leetcode sparse-checkout set --no-cone "/solution/*/*/README.md" "/LICENSE"
git -C data/sources/doocs-leetcode fetch --depth 1 origin 757ae31a437dc98972e73057f122a7c947acf8d7
git -C data/sources/doocs-leetcode checkout --detach 757ae31a437dc98972e73057f122a7c947acf8d7
python scripts/import_leetcode.py
```

脚本拒绝覆盖非空输出目录。`manifest.json` 记录数据 SHA、排除配置 SHA、实际排除及跳过条目。不得把新上游版本的统计套用到旧数据；重建后核对清单。
