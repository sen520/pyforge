# 本地开发指南

当前只维护中文需求转 JSON 数据清洗配置任务。使用 Python 3.12、原生 Windows、RTX 4080 SUPER，以及本地基础模型缓存。

## 安装

首次准备 Python 3.12 虚拟环境；已有环境时跳过创建：

```powershell
Set-Location E:\code\github\pyforge
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
python -m pip install -e ".[train,plot]"
pyforge doctor
```

使用 python -m pip 保证安装到当前解释器。当前固定训练依赖见 pyproject.toml。doctor 应显示 CUDA、BF16 支持和可用 GPU，不自动转 CPU 训练。

```powershell
hf download Qwen/Qwen2.5-Coder-1.5B-Instruct --cache-dir E:/code/github/pyforge/models/hub
```

模型文件放 models/hub，代码按源码位置定位缓存；后续训练与推理可使用 --offline。本流程不使用外部模型 API、Docker 或 API 密钥。Excel 导出额外读取 Codex 附带的 Node.js/artifact-tool，不在仓库安装 npm 包。

## 开发检查

```powershell
python -m unittest discover -s tests -v
pyforge validate datasets/data_cleaning/train.jsonl
pyforge validate datasets/data_cleaning/test.jsonl
pyforge validate datasets/data_cleaning/validation.jsonl
python scripts/check_data_cleaning_cases.py
```

单元测试用 mock 检查推理调用和进程调度，不会自动启动训练或付费调用。独立配置执行用例只覆盖列出的有限样本，不能当作全量模型正确率。

## 日常操作

按[数据清洗数据集指南](数据清洗数据集指南.md)执行训练、测试、验证、Excel 对比和使用示例。训练配置统一为 configs/train_4080.json，默认数据目录为 datasets/data_cleaning；每个新运行使用新输出目录。模型、虚拟环境、预测和表格位于忽略目录，不提交 Git。
