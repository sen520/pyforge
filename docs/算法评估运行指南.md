# 算法评估运行指南

## 首版范围

已从 doocs 验证候选集中冻结 20 道无需链表、二叉树或交互适配的算法题，共 100 个独立编写的测试用例。题面来源和许可保留在数据中。测试不是 LeetCode 官方隐藏测试，结果仅表示本地用例的单次生成通过率。

题库为 `datasets/benchmarks/doocs-leetcode/executable_v1.jsonl`，清单为同名 `.manifest.json`。包含整数回文、盛水容器、三数之和、电话号码组合、括号生成、数独、字符串、数字计算及数组等任务。题库包含期望输出，模型输入只能使用 `prompt`，不能传 `tests`、参考实现或报告。

## 环境与构建

需要已启动的 Docker Desktop Linux 容器引擎。题库已随 Git 提交，安装项目后只需准备镜像：

```powershell
docker pull python:3.12-slim
```

如需重建，运行 `python scripts/build_eval_subset.py --output datasets/benchmarks/doocs-leetcode/executable_v2.jsonl`。脚本读取 `datasets/benchmarks/doocs-leetcode/questions.jsonl`，拒绝覆盖现有题库；升级用例时使用新文件并冻结新 SHA。

## 预测格式与运行

每题一次生成，基础模型与微调模型使用相同题面、模板、贪心解码、最大生成长度和模型环境。UTF-8 JSONL 预测文件每行包含 id 和原始 response：

```json
{"id":"doocs-leetcode-0009","response":"```python\nclass Solution:\n    def isPalindrome(self, x: int) -> bool:\n        return str(x) == str(x)[::-1]\n```"}
```

模型输出唯一 Python 代码块，或整条回答仅含 Python 代码。多个代码块、未闭合代码块、语法错误均失败。保留原始输出，不手工修正。重复或未知预测 ID 会拒绝整批评估；缺答计入总题数。

```powershell
pyforge evaluate --suite datasets/benchmarks/doocs-leetcode/executable_v1.jsonl --predictions outputs/base_predictions.jsonl --report outputs/base_report.json
```

报告路径必须不存在。默认每题全部测试共用 5 秒墙钟预算，包含容器启动时间，可用 `--timeout 10` 调整，两模型必须一致。`--image` 可指定其他本地 Python 3.12 镜像，评估不自动拉取镜像。

一道题全部用例通过才计为通过。三数之和允许内外顺序不同，字符串组合允许外层顺序不同，但多余重复结果仍失败。其他结果严格比较 JSON 类型和值，布尔值不能冒充整数。

报告记录题数、通过数、pass_at_1、逐题状态、题库和预测 SHA、实际镜像 ID 与时间限制。状态包括缺答、提取/语法失败、执行异常、超时、输出超限、格式错误、答案错误和通过。只验证本地函数结果，不保证渐进复杂度或所有输入正确；不能将 20 题结果代表全部 3,422 题或整体编程能力。

## 隔离边界

宿主不执行候选代码。每题使用新容器，禁网、只读根文件系统、非 root、去除 capabilities、禁止提权；CPU 为 1、内存和交换总额 256 MB、进程数 32。只读挂载本题临时代码和输入，不挂载期望答案、模型、仓库或密钥。临时目录上限 16 MB，捕获输出约 64 KB，超时显式删除容器。

Docker 是执行隔离边界，不是针对主动攻击评估器的完整安全证明。候选代码和结果协议在同一 Python 进程，尚未实现防伪造；本版本用于普通模型答案验证，不用于恶意代码竞赛。不能给容器挂载 Docker socket 或额外宿主目录。

## 开发验证

单元测试不要求 Docker，集成测试显式开启：

```powershell
python -m unittest discover -s tests -v
$env:PYFORGE_DOCKER_TESTS = "1"
python -m unittest discover -s tests -v
Remove-Item Env:PYFORGE_DOCKER_TESTS
```

容器测试覆盖 20 题自有参考实现、错误答案、异常、超时、非 root、只读根目录及网络不可达。`tests/reference_solutions.py` 仅供执行器自检，不用于训练或模型提示。通过自检不代表基础模型或微调模型已通过评估。
