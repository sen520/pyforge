# 项目文件与归档说明

当前只维护数据清洗配置任务，按训练、测试、验证、Excel 对比、模型使用的顺序操作，完整命令见[数据清洗数据集指南](数据清洗数据集指南.md)。

## 目录职责

| 目录 | 内容 | Git |
| --- | --- | --- |
| src/pyforge/ | 当前数据、训练、预测、评估、使用示例和 CLI | 提交 |
| configs/train_4080.json | 当前 1.5B QLoRA 训练配置 | 提交 |
| scripts/ | 数据封装、有限检查、批量预测、评分、绘图和 Excel 导出 | 提交 |
| tests/ | 当前链路的 CPU/mock 单元测试 | 提交 |
| datasets/data_cleaning/ | 当前三个集合、完整作者原稿、检查记录、缩小前数据快照 | 提交 |
| datasets/archive/teacher_v1/ | 按此前要求保留的历史硅基流动数据，当前流程不读取 | 提交 |
| docs/、README.md、AGENTS.md | 当前操作、开发规则和数据约定 | 提交 |
| models/ | 基础模型缓存 | 保留、忽略 |
| outputs/ | adapter、检查点、训练清单、原始预测、评分、Excel、预览和本地备份 | 保留、忽略 |
| .venv/、.cache/、__pycache__/、.idea/ | 环境与临时缓存 | 忽略 |

## 当前脚本

| 入口 | 用途 |
| --- | --- |
| benchmark_data_cleaning.py | 一键测试、验证、基础/微调比较与 Excel 导出，可复用已有预测 |
| export_data_cleaning_comparison.mjs | Excel 汇总公式、逐题原始回答、筛选、冻结窗格和预览 |
| build_data_cleaning.py | 从完整作者原稿封装、分层抽样和校验，不生成需求或答案 |
| check_data_cleaning_cases.py | 复跑明确列出的有限参考配置执行用例 |
| predict_eval.py | 从只含 id/prompt 的题面批量生成原始回答和来源清单 |
| score_data_cleaning.py | 严格 JSON/配置匹配评分，未知或重复题号拒绝处理 |
| plot_training.py | 从运行日志绘制散点或损失趋势 |

所有新运行和评估都使用新的输出目录，已有模型权重和预测不覆盖。模型使用需要基础缓存、adapter/ 与 run_manifest.json；后者只是加载说明，不是模型权重。

## 历史保留与备份

历史硅基流动 JSON/JSONL 原始内容、生成记录和检查清单保留在 datasets/archive/teacher_v1，不参与当前训练。清理前的已提交工作区快照另存为本地 outputs/cleanup-backup-20261024.zip，原提交为 69bc359；该备份不随 Git 提交。当前数据、已训练模型与本次 Excel 不属于清理目标。
