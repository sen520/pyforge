# 首批种子题库

题库位置：`datasets/sources/seed_questions.jsonl`，共 100 道原创中文题目，面向 Python 3.12。构成为算法 40 道、日常编程 25 道、错误修复 20 道、测试生成 8 道、代码解释 7 道。

当前是待审核题目，不含 DeepSeek 答案，也没有经过执行验证。不能直接传给 `pyforge train`；训练入口要求带完整 assistant 回答的 messages 数据。

算法覆盖数组、字符串、搜索、基础数论、动态规划、图与矩阵。日常任务覆盖数据处理、JSON/CSV、日期时间、装饰器、配置校验。修复题附带有缺陷的代码与预期行为；测试题给出接口契约；解释题提供具体片段。

每条包含 id、task_type、title、prompt、answer_requirements、来源、分组、Python 版本和审核状态。原创来源声明不代表已选择开放许可证，`license` 暂记为 `project_original_pending_license`，对外发布前需确定许可证。

使用前先人工审核歧义、难度与分组。同一任务的实现、修复和测试已合并部分 group_id，后续发现语义相近题仍需合并。应在批量作答与调参前按 group_id 冻结集合，不得将改写后的测试题回流到训练数据。

交给教师模型时，将 `prompt` 与 `answer_requirements` 拼成用户请求。要求输出简短说明及完整代码，算法注明复杂度，不要求冗长推理。回答 token 上限需给足，之后按真实 tokenizer 检查长度，不能硬截断代码以迁就 4060 的 512 token 冒烟配置。

生成后保留原始响应、确切模型 ID、参数、时间、token 用量与题目 ID；代码在隔离执行器中验证，人工抽查后才导出训练 JSONL。独立测试优先，不能仅用同一模型生成的测试确认同一模型的答案正确。

题库生成器不联网、不调用付费 API，拒绝覆盖已有文件。若要重新生成进行比较，请使用新文件：

```powershell
python scripts/make_question_bank.py datasets/sources/seed_questions_v2.jsonl
```
