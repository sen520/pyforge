当前方向是中文需求转固定 JSON 数据清洗配置，四种操作的规则见[配置约定](../datasets/data_cleaning/配置约定.md)，来源与划分见[数据集说明](../datasets/data_cleaning/数据集说明.md)。只生成配置，真实数据由固定程序处理。

## 检查与重建

在 `E:\code\github\pyforge` 激活 Python 3.12 虚拟环境。以下 tokenizer 快照为当前本地缓存，迁移或改基础模型后替换为对应快照路径。命令只读取本地 tokenizer，不加载模型权重，不调用模型 API。

```powershell
Set-Location E:\code\github\pyforge
python scripts/build_data_cleaning.py --tokenizer models/hub/models--Qwen--Qwen2.5-Coder-1.5B-Instruct/snapshots/2e1fd397ee46e1388853d2af2c993145b0f1098a --check
pyforge validate datasets/data_cleaning/train.jsonl
pyforge validate datasets/data_cleaning/validation.jsonl
pyforge validate datasets/data_cleaning/test.jsonl
python scripts/check_data_cleaning_cases.py
python -m unittest discover -s tests -v
```

去掉 `--check` 会从已有原稿重新封装三个集合并更新清单。脚本不创建新需求或答案：完整原稿仍各 1,000 条，当前输出训练 1,000 条、验证 200 条、测试 200 条。抽样按场景与操作序列分层、固定 SHA256 排序，不读取模型得分，不自动过滤超长样本。先修改原稿再重建会改变数据哈希，已有训练不能据此恢复。

## 留出集计分

当前测试只有 200 条，验证也为 200 条。已完成的 data-cleaning-001 可直接测试，无须重训；其原验证 loss 属于旧 1,000 条验证集。完整旧数据保留在 `datasets/data_cleaning/archive/full_v1`，旧运行恢复时可用该目录匹配原始哈希。

旧 prompts.jsonl 仍可能包含 1,000 题，需要重新提取当前题面并使用新输出目录（例如 outputs/data-cleaning-eval-002），不能复用旧题面后期望自动变成 200 题。旧 1,000 条预测也不能直接送给当前评分器，未知题号会被拒绝。基础与微调模型都要使用同一份新题面。


预测文件为 UTF-8 JSONL，每行包含 `id` 和模型原始 `response`。生成时只能提供样本中的 system/user 消息，不提供 assistant 参考答案。禁止把参考答案写入预测文件后当成模型成绩。

```powershell
python scripts/score_data_cleaning.py --data datasets/data_cleaning --split validation --predictions outputs/data-cleaning-validation-predictions.jsonl --report outputs/data-cleaning-validation-report.json
python scripts/score_data_cleaning.py --data datasets/data_cleaning --split test --predictions outputs/data-cleaning-test-predictions.jsonl --report outputs/data-cleaning-test-report.json
```

报告拒绝覆盖。缺答计入分母，重复或未知题号拒绝评分；Markdown 包裹、非法 JSON、重复键和 schema 错误都不算格式通过。`schema_valid_rate` 只评价格式，`exact_config_accuracy` 比较参考配置：忽略 JSON 对象键顺序与空白，保留数组顺序与 JSON 值类型。某些执行等价配置仍可能被严格匹配判错，所以该指标不是执行结果正确率。

基础模型和微调模型必须使用相同 system 提示、基础快照、题面和生成规则分别计分。原有 `pyforge benchmark` 面向 LeetCode Python 代码，不适用 JSON 配置，不要用原来的 20 题评估这个新方向。
