# 首批硅基流动教师数据

> 历史版本。当前默认训练数据为 `datasets/`，由 Codex 直接编写并完成 100 题检查。不要将两个版本直接合并；原始来源与审核记录在此保留。

教师模型：`deepseek-ai/DeepSeek-V4-Pro`。输入来自项目 100 道原创种子题，不使用 doocs 验证题作训练素材。

本轮收到 99 条完整回答，响应 usage 合计 51,034 tokens：输入 12,826，输出 38,208。HTTP 失败与结果未确认请求的费用不在此统计内，以平台账单为准。`seed-022` 网络异常、结果未确认，未重复调用，因此没有该题答案。

通过独立 Docker 功能用例的 83 条问答按生成前冻结的 group_id 分组导出：

| 文件 | 条数 | 用途 |
| --- | ---: | --- |
| train.jsonl | 75 | 微调训练 |
| validation.jsonl | 4 | 验证 loss |
| test.jsonl | 4 | 原创问答留出集，不参与调参 |
| pending_review.jsonl | 16 | 1 条区间合并逻辑错误、8 道测试生成题、7 道解释题，暂不训练 |

`generation_manifest.json` 记录源题 SHA、模型、提示、生成参数及预先冻结的集合归属；`generation_summary.json` 记录调用结果与 token 用量；`verification_manifest.json` 记录执行检查脚本 SHA、候选输入 SHA 和 Docker 镜像；`verification.jsonl` 保留逐题审核结果；`dataset_manifest.json` 记录条数与最终文件 SHA。

消息仅包含 system/user/assistant；保留原始 id、group_id、任务类型和模型来源。通过检查的实现保留首个实现块，移除额外 pytest 测试与夹具，不修改实现函数体。完整原始响应仍保存在生成机器的 outputs/teacher_v1，未提交。语法检查与功能检查结果写在 verification 字段，human_review 仍为 false。

这是一批小规模实验数据，功能用例不能证明所有输入、复杂度和解释均正确。只有 4 条验证与 4 条留出样本，无法用于可靠的整体能力结论。正式扩容前需补充测试、人工抽查和任务多样性。来源许可仍保留待确定状态，不代表已选定开放数据许可证。

本批数据可直接用于现有训练入口：

```powershell
pyforge train --config configs/train_4080.json --data datasets/archive/teacher_v1 --output outputs/train-teacher-001
```

本批已用本地 Qwen2.5-Coder-0.5B-Instruct 模板验证标签屏蔽与长度，83 条均不超过 512 tokens，最长 504，可用于现有 4060 冒烟配置；统计见 encoding_report.json。换模型时需重新核对。独立算法执行评估仍使用 datasets/benchmarks/doocs-leetcode/executable_v1.jsonl，与本目录 validation.jsonl 的用途不同。
