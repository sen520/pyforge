# 数据集目录

按训练方向分别保存数据：

| 目录 | 用途 | 状态 |
| --- | --- | --- |
| [leetcode](leetcode/数据集说明.md) | 既有 Python / LeetCode 训练、验证、测试及来源、审计、评估、历史数据 | 已迁移，样本字节与 SHA256 不变 |
| [data_cleaning](data_cleaning/数据集说明.md) | 中文需求转 JSON 数据清洗配置 | 模型直接编写；当前训练 1,000 / 验证 200 / 测试 200，完整原稿与旧版已保留 |

当前训练、算法评估和历史脚本的默认数据目录仍指向 `datasets/leetcode`。新方向准备好数据后需显式选择对应目录，不混合两个任务。

历史 JSON 清单、样本来源和 reports 中的路径保留生成时原值；旧 `datasets/` 下的内容现对应 `datasets/leetcode/`，原始哈希保持可核验。既有训练输出未移动，恢复或评估时使用 `--data datasets/leetcode`，旧接口修复前模型仍需按训练数据审计文档重建原数据。
