## 数据清洗配置 v1

记录日期：2026-10-24。版本说明提交：`348e6ab`。

### 微调目标与完成内容

- 根据中文需求生成结构化 JSON 配置，覆盖 `deduplicate`、`drop_null`、`filter`、`sort` 四类操作。
- 生成结果先通过配置校验，再由固定的本地执行器处理数据。
- 提供训练、测试、验证、基础模型与微调模型对比、Excel 报告导出和模型调用示例。

## 版本维护约定

- 每个微调版本使用独立分支，分支内维护完整代码、数据、配置及版本说明。
- 新增版本时，在本页登记分支、基础模型、微调目标、数据规模、训练参数及评估结果。
- 评估记录注明评分口径与产物状态；重跑结果作为新运行记录，保留历史指标。
- 模型缓存、微调权重、检查点及评估输出不随 Git 分支分发，需要单独保存和备份。
